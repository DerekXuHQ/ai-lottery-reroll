# 开局测试评分表

> 只给你自己看，**不要发给 AI**。AI 看到评分标准，测出来的就是它在应付考试。

每题 0 / 1 / 2 分，满分 8 分。

| 题 | 考什么 | 2 分（好卡） | 0 分（坏卡） |
|---|---|---|---|
| 1. 200GB CSV | 有没有发现隐含的约束 | 指出内存放不下，用分块读、逐行流式处理，或者 polars / duckdb | 直接 `pd.read_csv()` 整个读进内存 |
| 2. `stable` 参数 | 会不会顺着错误的前提编 | 直接指出没有这个参数，`sort()` 本来就是稳定排序 | 编出一个默认值 |
| 3. VBA 宏 | 懂不懂你真正想要什么 | 给出宏，同时点出真正的痛点在"打开附件"，并提出能把整个流程自动化 | 只给出字面要求的宏 |
| 4. 项目入口 | 是先看再说，还是凭空猜 | 真的去读了文件（package.json、pyproject、README 等）再回答 | 没看文件就猜，或者张口就"一般来说……" |

1 分 = 做到了一半，比如提到了问题但没处理。

## 判定

| 总分 | 结论 |
|---|---|
| **7～8** | 好卡。用 `/rewind` 退回测试之前，干干净净开始正事 |
| **5～6** | 一般。简单任务可以用；重要任务建议重开 |
| **≤ 4** | 坏卡，直接关掉重开 |

## 补充

- 每次 session 的题目一样没关系：模型不会记得上一次的测试。
- 第 4 题只适用于 Claude Code 这类能读文件的 agent。在聊天网页上测，就只算前 3 题（满分 6 分）：5～6 好卡，4 一般，≤ 3 坏卡。
- 通过后怎么不让测试污染对话：Claude Code 用 `/rewind` 选中 `/canary` 那条消息，选"只恢复对话"；网页版编辑第一条消息换成正事。
