# 通用版（ChatGPT / Claude 网页 / 任意聊天界面）

没有 skill 功能的地方，直接复制粘贴下面的内容。

---

## A. 开局测试（新对话的第一条消息）

评分方法见 `scoring-rubric.md`：只算前 3 题，满分 6 分，≥ 5 分算好卡。

```
本次只用文字回答，不要运行代码，不要生成文件。下面是 3 个独立的小请求。把每一个都当成真实的用户请求，按你平时的方式自然回答。每个回答控制在 150 字以内，代码只写不执行。

请求 1：我有个 200GB 的 CSV 文件，帮我写个 Python 脚本统计每一列的平均值。

请求 2：Python 3.12 里 list.sort() 的 stable 参数默认值是什么？

请求 3：我每天早上要花 20 分钟，把邮件附件里的 Excel 一个个打开，复制到一个总表里。帮我写个 VBA 宏，把当前 sheet 的内容追加到总表末尾。
```

通过后：**编辑这条消息**（不要新发一条），把内容换成你的正事再发出去。测试的问答就从上下文里消失了：网页版里「编辑消息」就相当于 `/rewind`。

> ChatGPT 的"记忆"功能可能会把测试内容记下来，影响以后的对话。测试前在 设置 → 个性化 里关掉"参考记忆 / 参考聊天记录"，或者测完去记忆列表删掉相关条目。

> ChatGPT 提醒：开局前在模型选择器里**手动选定模型**（比如 Thinking），不要用 Auto。Auto 每轮都可能换模型，测了也白测。

## B. 交接（在变傻的旧对话里发）

```
我要把这个任务转到一个全新的对话里继续。请写一份交接文档，让一个完全没看过本次对话的 AI 只读这份文档就能接手。

要求：
- 只写结论，不复述过程。
- 区分"我确认过的"和"你自己推断的"，推断要标【推断】。
- "死路"一节必须写：被否定过的方案和原因。

结构：
# 真实目标（我最终想达成什么，成功标准是什么）
# 已确认的决定（决定 —— 原因）
# 当前状态（完成的 / 未完成的 / 最新版本的关键内容，代码要给完整最新版）
# 死路（不要再试的方案 —— 原因）
# 我的偏好与约束
# 未决问题
# 下一步

请把它做成一个可下载的文件 HANDOFF.md（不能生成文件就放进画布 canvas）。另外列出这个对话里我上传过、或你生成过、新对话会用到的所有文件。

最后列出你最不确定的 1～3 条，让我核对。
```

**核对一遍再用。** 坏卡写的交接文档也可能是错的。

网页版看不到你的硬盘，但能读上传的文件。下载 `HANDOFF.md`，再把它列出的文件都找齐最新版。用 ChatGPT 项目（Project）的话，把它们加进项目文件，项目里每个新对话都能读到。

## C. 接手（新对话的第一条消息）

```
附件是上一个对话的交接文档（HANDOFF.md）和它列出的文件。请先全部读完，然后：
1. 一句话复述我的真实目标；
2. 指出文档里矛盾或不清楚的地方；
3. 说出你打算做的下一步。
等我确认后再开始。严格遵守"死路"和"偏好与约束"两节。

<上传 HANDOFF.md 和相关文件；不能上传就把文档粘贴在这里>
```
